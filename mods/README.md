# Mods

Drop-in mods for [MSML](../README.md). To install one:

1. Install MSML first (see the [main README](../README.md)).
2. Download the mod's `.zip` below.
3. In Moon Sweepers, open **MODS > ADD MOD** and pick the zip (or extract it into `<game>\Mods\`).
4. Restart the game (**RESTART TO APPLY**).

| Mod | Version | Description | |
|---|---|---|---|
| **Better Belts** | 0.1.0 | Pneumatic tubes: glass tubes sunk into the ground that shoot capsules along up to 5x as fast as conveyor belts (10x in SETTINGS). | [Download](https://github.com/Wehrum/MSML/raw/main/mods/BetterBelts-0.1.0.zip) |
| **Debug Menu** | 0.3.0 | Testing tools. In-game, open the pause menu (Esc) and a DEBUG panel appears on the right (F7 hides or shows it). | [Download](https://github.com/Wehrum/MSML/raw/main/mods/DebugMenu-0.3.0.zip) |
| **Hello World** | 0.1.0 | A tiny example mod. It shows a "Hello World mod loaded" label in the top-left corner for 30 seconds after the game starts, and logs a message whenever the main menu opens. | [Download](https://github.com/Wehrum/MSML/raw/main/mods/HelloWorld-0.1.0.zip) |
| **Hex Harvester** | 0.5.0 | A new vehicle, sold in the garage for $100,000: the Hex Harvester. A six-wheeled harvester with a hex-glass cab, a glass hex silo that visibly fills with dust as you clean, and a 25 m truss-mounted sweeper head with five brush pods. It clears a whole hex in one pass. | [Download](https://github.com/Wehrum/MSML/raw/main/mods/HexHarvester-0.5.0.zip) |
| **MoonFixerUpper** | 0.1.0 | Fixes for bugs in the game itself. Each fix can be turned off in SETTINGS (here, or MOD SETTINGS in the pause menu). | [Download](https://github.com/Wehrum/MSML/raw/main/mods/MoonFixerUpper-0.1.0.zip) |
| **MoonSweeper+** | 0.1.0 | The official MSML quality-of-life mod: small fixes for everyday annoyances. Every fix can be turned on or off with SETTINGS (here, or MOD SETTINGS in the pause menu). | [Download](https://github.com/Wehrum/MSML/raw/main/mods/MoonSweeperPlus-0.1.0.zip) |
